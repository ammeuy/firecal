# requests

Need something from a directory you do not own? Do not edit it. Add a file here named
`<you>-to-<owner>-<topic>.md` with: what function, type or file you need, its input and output, and the test
that would prove it. The owner answers by doing it or by saying why not. Meanwhile, work against a stub.

This is the only directory every branch may edit. Delete a request file when it is done.
